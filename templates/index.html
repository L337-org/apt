L337 APT repository

This is a flat APT repository for L337-org projects, refreshed automatically from each project's GitHub Releases. It is not meant to be browsed - install via apt: 

curl -fsSL https://apt.l337.org/l337-apt.gpg | sudo tee /usr/share/keyrings/l337-apt.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/l337-apt.gpg] https://apt.l337.org/ ./" | sudo tee /etc/apt/sources.list.d/l337-apt.list
sudo apt update

Packages currently published here:

  • send-to-influx - see its README for setup and its Releases page for notes and direct .deb downloads.

This repository is managed by L337-org/apt - contents are regenerated automatically, don't edit by hand. (send-to-influx.gpg is the same signing key as l337-apt.gpg under its historical name.)
